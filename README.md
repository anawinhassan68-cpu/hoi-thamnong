# ถ้อยทำนอง

เว็บแอปแปลเนื้อเพลงภาษาอังกฤษเป็นภาษาไทย โดยแสดงผลเทียบทีละบรรทัด รองรับสำนวนแปลหลายแบบ และเก็บบรรทัดว่างระหว่างท่อนเพลง

## สิ่งที่ต้องมี

- Node.js 20 ขึ้นไป
- OpenAI API key ที่มีสิทธิ์เรียกโมเดลที่ตั้งไว้

## รันบนเครื่อง

1. แตกไฟล์ ZIP และเปิดโฟลเดอร์ `thoi-thamnong`
2. ติดตั้งแพ็กเกจ

   ```bash
   npm install
   ```

3. คัดลอก `.env.example` เป็น `.env.local`
4. ใส่ API key ใน `.env.local`

   ```env
   OPENAI_API_KEY=ใส่คีย์จริงของคุณ
   OPENAI_MODEL=gpt-4.1-mini
   ```

5. เริ่มเว็บ

   ```bash
   npm run dev
   ```

6. เปิด `http://localhost:3000`

**สำคัญ:** ห้ามใส่คีย์ในไฟล์หน้าเว็บหรือใช้ชื่อตัวแปรที่ขึ้นต้นด้วย `NEXT_PUBLIC_` เพราะจะเปิดเผยคีย์ให้เบราว์เซอร์เห็น

## ดีพลอยบน Vercel

1. สร้าง Git repository แล้ว push โฟลเดอร์นี้ขึ้น GitHub
2. เข้า Vercel แล้วเลือก Add New → Project และนำเข้า repository
3. ใน Project Settings → Environment Variables เพิ่ม
   - `OPENAI_API_KEY` = API key ของคุณ
   - `OPENAI_MODEL` = `gpt-4.1-mini` (หรือโมเดลที่บัญชีคุณใช้งานได้)
   - `OPENAI_BASE_URL` = ไม่ต้องใส่หากใช้ OpenAI API โดยตรง
4. กด Deploy

เมื่อต้องเปลี่ยน environment variables ให้ redeploy เพื่อให้ฟังก์ชันเซิร์ฟเวอร์อ่านค่าใหม่

## วิธีทำงาน

- หน้าเว็บแยกบรรทัดตามต้นฉบับ และนับบรรทัดว่างรวมในเพดาน 400 บรรทัด
- ส่งเฉพาะบรรทัดที่ไม่ว่างไปยัง `/api/translate` ครั้งละไม่เกิน 30 บรรทัด
- นำคำแปลกลับไปใส่ตำแหน่งเดิม จึงคงช่องว่างระหว่างท่อนไว้
- เก็บบันทึกจากรอบแรกเท่านั้น
- คำแปลที่โมเดลส่งกลับมาไม่ครบจะเติมเป็นสตริงว่าง ไม่ทำให้หน้าเว็บล่ม
- ปุ่มแปลถูกปิดระหว่างทำงาน และไม่มีการลองซ้ำอัตโนมัติ

## ข้อจำกัด rate limit

ตัวอย่างนี้จำกัด 12 คำขอต่อ IP ต่อนาทีที่ API route โดยใช้หน่วยความจำของแต่ละ instance เหมาะสำหรับเดโมหรือการใช้งานขนาดเล็ก แต่บน serverless อาจไม่ใช่ตัวนับร่วมกันทุก instance และอาจรีเซ็ตเมื่อ instance หยุดทำงาน

หากเปิดใช้จริงกับผู้ใช้จำนวนมาก ควรเปลี่ยน Map ใน `app/api/translate/route.js` เป็น Redis แบบ shared เช่น Upstash และตั้งค่า rate limit ที่ขอบระบบด้วย

## ความปลอดภัยและค่าใช้จ่าย

- API key อยู่ใน environment variable ฝั่งเซิร์ฟเวอร์เท่านั้น
- API จำกัด request body 40 KB และจำกัด 30 บรรทัดต่อคำขอ
- หน้าเว็บใช้ React text rendering ซึ่ง escape ข้อความ ไม่แทรก HTML จากผู้ใช้หรือโมเดล
- ทุกครั้งที่แปลมีค่าใช้จ่ายตามโมเดลและจำนวน token ที่ส่งไปยัง API ควรกำหนด spending limit ในผู้ให้บริการ API ด้วย
